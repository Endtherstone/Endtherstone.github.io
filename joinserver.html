เซิร์ฟปิด 22:00 น. | เปิดตามใจแอดมิน

สิ่งที่ต้องทำเมื่อเข้าเกม

1. อยู่ในโหมด Adventure

เมื่อเกิดมาคุณจะยังทุบหรือวางบล็อกไม่ได้ ให้เดินตามทางไปที่จุดศูนย์กลาง

2. ไปที่ "เทศบาล"

หาป้ายหรือสมุดลงชื่อที่เทศบาล เพื่อเขียนคำขอที่ดินสำหรับสร้างบ้าน

3. รอคุยกับ Admin

Admin จะสอบถามและพาไปดูพื้นที่ พร้อมกับทำระบบ Claim ที่ดินให้คุณ

4. ได้สิทธิ์สร้างเมือง!

เมื่อได้พื้นที่ของตัวเองแล้ว คุณถึงจะสามารถทุบ วาง และสร้างบ้านได้ครับ

กฎเหล็ก (ฝ่าฝืน = แบนถาวร)

  • ห้ามแอบไปสร้างในป่า หรือนอกเขตเมืองเด็ดขาด
  • ห้ามทุบทำลาย หรือก่อกวนพื้นที่ของคนอื่น
  • สิทธิ์ขยายพื้นที่ ขอเพิ่มได้ถ้าสร้างที่เก่าเสร็จแล้ว

ระบบก๊อปปี้ IP (147.185.221.223) ไว้ให้คุณแล้ว
1. เข้าเกมไปที่เมนู Add Server
2. ช่อง Server Address ให้กดแช่แล้ว วาง (Paste)
3. ช่อง Port ใส่เลข 12004
