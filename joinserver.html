กฎเหล็ก (ฝ่าฝืน = แบนถาวร)
  • ห้ามแอบไปสร้างในป่า หรือนอกเขตเมืองเองเด็ดขาด
  • ห้ามเกรียน ทุบทำลาย หรือก่อกวนพื้นที่ผู้อื่น
  • จะขอขยายพื้นที่เพิ่มได้ เมื่อสร้างหลังเก่าเสร็จแล้วเท่านั้น

เขียนเสร็จแล้วยืนยันเรื่องทิ้งไว้ รอ Admin พาไปเปิดระบบ Claim ให้ครับ

คู่มือฉบับเต็ม

1. วิธีเพิ่มเซิร์ฟเวอร์

เปิดเกมเลือกแผง Servers เลื่อนลงล่างสุดกด Add Server ใส่ข้อมูล:

Server Address: 147.185.221.223
Port: 12004

2. การเดินทางเข้าสู่เมือง

สำคัญ: เมื่อโหลดเข้าแมพมาได้แล้ว ให้ทำการ "เดินตรงไปข้างหน้าตามลูกศรบนพื้นถนนอย่างเดียว" ห้ามเลี้ยวหรือเดินออกนอกเส้นทางเด็ดขาด จะเจออาคารเทศบาลตั้งอยู่ด้านหน้า

3. การขอพื้นที่สร้างบ้าน

เดินเข้าเทศบาล หยิบสมุดในกล่องข้างแท่นอ่านมาเขียนให้ครบถ้วน:

  • ระบุ รูปแบบสิ่งก่อสร้าง ที่ต้องการทำอย่างชัดเจน
  • ระบุ ขนาดพื้นที่ (กว้าง x ยาว) ที่ต้องการใช้สิทธิ์
  • ระบุ ชื่อในเกม ให้ชัดเจน
  • เขียนเสร็จแจ้งรอ Admin ตรวจสอบเพื่อตั้งค่าระบบ Claim กันคนเกรียน

4. กฎเหล็กห้ามฝ่าฝืน

ห้ามแอบไปสร้างในป่าหรือนอกเขตเมืองเด็ดขาด, ห้ามทุบทำลายสิ่งก่อสร้างผู้อื่น, และขอขยายพื้นที่เพิ่มได้เมื่อสิ่งก่อสร้างเดิมเสร็จสมบูรณ์แล้วเท่านั้น (ฝ่าฝืนแบนถาวร)
