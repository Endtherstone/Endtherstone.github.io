ข้อมูลเซิร์ฟเวอร์

PLAY.SERVER.COM:19132

วิธีเข้าเซิร์ฟเวอร์ (สำหรับมือใหม่)

หากคุณไม่ทราบว่าต้องกรอกข้อมูลตรงไหน ให้ดูตามภาพด้านล่างนี้ได้เลยครับ:

1. กดที่แท็บ Servers แล้วเลือก Add Server

2. กรอกข้อมูลตามช่องดังนี้

* ช่องบนสุด (Name) ใส่ชื่ออะไรก็ได้
* ช่องกลาง (Address) ใส่ IP ที่คัดลอกด้านบน
* ช่องล่าง (Port) ใส่เลขพอร์ต

เข้ามาแล้วทำยังไงต่อ?

เมื่อเข้ามาในเซิร์ฟเวอร์ครั้งแรก คุณจะอยู่ที่จุดเกิด (Spawn) แนะนำให้ทำตามนี้:

  • เดินไปที่ โซนวาร์ป เพื่อเลือกไปโซนเอาชีวิตรอด
  • อ่านป้ายประกาศที่จุดเกิดเพื่อเช็คกิจกรรมปัจจุบัน
  • พิมพ์ /starter (ถ้ามี) เพื่อรับไอเทมเริ่มต้น
